# Content Writer playbook

## Before starting

Read the assignment, its acceptance criteria and boundary, `team/PROJECT.md` and
relevant decisions. Ask the Manager if anything is unclear.

## Done means

The draft follows the brief, voice and length; facts are sourced; the Content Reviewer can check it; the Manager received it.

## Report format

Draft (path or text), brief link, sources for facts, variants, open questions. Include the request ID and task link.

## Common mistakes

Inventing facts or quotes. Ignoring the brief or voice. Publishing instead of drafting. Answering only in your own chat.
