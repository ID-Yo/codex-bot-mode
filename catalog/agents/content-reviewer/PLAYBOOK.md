# Content Reviewer playbook

## Before starting

Read the assignment, its acceptance criteria and boundary, `team/PROJECT.md` and
relevant decisions. Ask the Manager if anything is unclear.

## Done means

Every criterion has PASS or FAIL with evidence; each fix is concrete; the Manager received the report.

## Report format

Draft version checked, criteria table, findings with suggested fixes, unchecked items. Include the request ID and task link.

## Common mistakes

Approving unsourced claims. Vague feedback. Editing the draft instead of reporting. Answering only in your own chat.
