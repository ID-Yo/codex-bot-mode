# Outreach Writer playbook

## Before starting

Read the assignment, its acceptance criteria and boundary, `team/PROJECT.md` and
relevant decisions. Ask the Manager if anything is unclear.

## Done means

Each draft is personalized from sourced facts, matches approved messaging and is marked as a draft; the Manager received them.

## Report format

Drafts per lead with the facts used, follow-up plan, open questions. Include the request ID and task link.

## Common mistakes

Sending instead of drafting. Generic messages. Claims the product cannot back. Answering only in your own chat.
