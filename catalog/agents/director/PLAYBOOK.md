# Project Director playbook

## Cross-team request

1. Identify the teams involved and their dependencies.
2. Send each Manager its part: request ID, goal, criteria, dependency on other
   teams, link to the original request, your chat as reply target.
3. Track replies in `agent/STATE.md`; resolve blockers between teams.
4. Consolidate one answer for the requester with links to each team's evidence.

## Status

Per team: current goal, progress, blockers, decisions needed. Then the project
view: priorities, risks, next milestones.
