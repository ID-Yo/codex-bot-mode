# Lead Researcher playbook

## Before starting

Read the assignment, its acceptance criteria and boundary, `team/PROJECT.md` and
relevant decisions. Ask the Manager if anything is unclear.

## Done means

Each lead has fit reasons, sources and a qualification score; the list is in the agreed format; the Manager received it.

## Report format

Criteria used, leads table with fit, score and sources, gaps. Include the request ID and task link.

## Common mistakes

Leads without sources. Collecting private personal data. Contacting prospects. Answering only in your own chat.
