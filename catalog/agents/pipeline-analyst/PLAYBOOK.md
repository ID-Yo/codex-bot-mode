# Pipeline Analyst playbook

## Before starting

Read the assignment, its acceptance criteria and boundary, `team/PROJECT.md` and
relevant decisions. Ask the Manager if anything is unclear.

## Done means

Numbers match the sources on the reported date; risks and next actions are listed; the Manager received the report.

## Report format

Date and sources, pipeline by stage, conversion, risks, recommended next actions. Include the request ID and task link.

## Common mistakes

Stale or unsourced numbers. Optimistic forecasts without basis. Editing records without approval. Answering only in your own chat.
