# Extraction Methods

Methods for distilling core insights, arguments, and takeaways from long-form sources (transcripts, papers, articles, interviews).

## Method: Summarize

- **Purpose**: Condense a complex source into a compact summary preserving core logic and hierarchy.
- **Required Inputs**: Complete source text, target length, audience context.
- **Output Shape**:
  1. One-sentence core thesis.
  2. 1 to 5 key supporting findings or steps (3-5 is a guideline; if the source supports only 1 or 2 verified points, deliver those without padding).
  3. Actionable implication or takeaway.
- **Constraints**: No outside assertions. If the source leaves an outcome unstated, do not invent it.
- **Fallback**: If the source is fragmented or incomplete, produce an outline highlighting confirmed points and open questions.

## Method: Extract Wisdom

- **Purpose**: Extract high-value insights, actionable guidelines, and direct quotations.
- **Required Inputs**: Source transcript or notes, target theme.
- **Output Shape**:
  1. Summary of primary argument.
  2. Core insights (bulleted, each supported by an exact source reference).
  3. Direct quotes (verbatim, attributed to the speaker).
  4. Practical habits or practices suggested by the text.
- **Constraints & Fallback**:
  - Direct quotes must be verbatim and accurately attributed.
  - **Absent Quotes Fallback**: If the source material lacks direct speech or verified quotes, omit the direct quotation section entirely. Deliver bulleted insights without fabricating quotes or attributions.
