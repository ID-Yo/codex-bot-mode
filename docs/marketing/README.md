# Marketing — optional

Use this category for durable, evidence-backed understanding of the audience,
alternatives and offer. Each topic is an independently editable Markdown field;
there is no database and no need to load the whole category for one question.

| Question | Read / update |
|---|---|
| Who has the problem, and who is a poor fit? | [Ideal customer profile](ideal-customer-profile.md) |
| What do people use instead, including doing nothing? | [Competitors and alternatives](competitors.md) |
| Which category and differences should the audience understand? | [Positioning](positioning.md) |
| What outcome makes the offer worth choosing? | [Value proposition](value-proposition.md) |
| How should that evidence be expressed to the audience? | [Messaging](messaging.md) |

Read only the relevant file and its cited evidence. Link related fields instead of
duplicating their contents. These pages begin as draft templates, not accepted
claims. Fill them for the actual project; distinguish research, assumptions and
owner-approved decisions. Identify the owner and last review date in each page.

Original interview notes, decks and images belong in [Human Materials](../../human-materials/README.md).
Reconcile that index when relevant, inspect actual content before citing it and
honor its privacy boundaries. Operational product requirements belong in
[README](../../README.md), visual rules in [Design](../design/project-roster.md).
Acceptance and changes follow [AGENTS.md](../../AGENTS.md). Add future
topics only for an actual distinct need and route them through the [index](../00-index.md).
