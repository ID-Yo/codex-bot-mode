# Positioning

## Audience and frame of reference
For software developers and technical leads using Codex Desktop, Codex Bot Mode is an operational framework that structures persistent multi-agent specialist teams inside native desktop chats.

## Meaningful difference
Codex Bot Mode runs locally on developer workstations alongside Codex Desktop using a local loopback web interface (Codex Office). It provides distinct persistent roles (Manager, Developer, Reviewer, Verifier, Monitor), per-agent project-scoped file memory (directory organization, not runtime sandboxing), version-checked request tracking with reminders, and a local loopback team room interface without using a separate orchestration SaaS (while model API providers continue to process prompt context).

## Positioning statement
For software developers using Codex Desktop on Windows (other platforms untested), Codex Bot Mode is a local-first multi-agent framework (proposed hypothesis) that coordinates software tasks across specialized roles (Manager, Developer, Reviewer, Verifier, Monitor) using native desktop chats, backed by version-checked request tracking with reminders, a prescribed dual-gate review workflow, and per-agent project-scoped file memory.

## Boundaries and review
The framework does not provide fully autonomous cloud microservices and does not bypass human owner authorization. All decisions, standing approvals, and release workflows remain under owner control.
