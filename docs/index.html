FROM CATALOG TO PROJECT

Make the first step concrete.

  1. Read the setup guide. Use Codex Desktop, Python and the repository tools. GitHub CLI is needed for GitHub tracking and remote catalog fetches.
  2. Choose a team and tracking. Review the plan, role boundaries and GitHub/local/both selection before installation.
  3. Appoint and verify. Load each installed profile, check its own memory and chat identity, then run a bounded task.
