# Reusable Templates

These files are copyable markdown forms for project artifacts. Fill in placeholders before saving a real record.

| Template | Purpose |
|---|---|
| [decision](decision.md) | Architectural and project decisions |
| [fact](fact.md) | Verified factual claims with dates and sources |
| [procedure](procedure.md) | Repeatable, verifiable operational procedures |
| [handoff](handoff.md) | Structured session and task handoffs |
| [contradiction](contradiction.md) | Conflicting facts or requirements requiring resolution |
| [episode](episode.md) | Record of observed outcomes and lessons |
| [skill](skill.md) | Candidate skill instructions |

Canonical document templates are drafts until reviewed. A procedure candidate is not an executable agent skill.
