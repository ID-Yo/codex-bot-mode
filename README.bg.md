# Codex Bot Mode (CBM)

[English](README.md) · [Български](README.bg.md)

> Постоянни агенти и екипи в Codex Desktop: Manager за всеки екип, Project Director за проекти с няколко екипа, личен Chief of Staff, споделена памет и локален Office за стаи на екипите.

Неофициален проект на общността; не е свързан с OpenAI и не е одобрен от тях. „Codex“ е име на продукт на OpenAI.

## Защо

Повечето инструменти за много агенти изграждат нова среда: собствен runtime, собствен чат, собствени права. Codex Desktop вече има всичко нужно за един агент: чатове, които пазят контекста, проекти, skills, plugins, връзки към услуги, инструменти и вашите правила за одобрение. CBM не замества нищо от това, а го структурира и надгражда:

- **Идентичност.** Всеки агент е обикновен Codex чат, който зарежда профил (роля, характер, наръчник, правила) и собствена проверена памет.
- **Екипи.** Агентите са в екипи с Manager; проектите с няколко екипа имат Project Director; вашият Chief of Staff е единната входна точка за всички проекти.
- **Координация.** Списъкът с участници пази текущия линк към чата на всеки агент; регистърът на заявките следи всяка заявка да получи отговор там, откъдето е дошла, с напомняния.
- **Памет, която се пренася.** Научените уроци са файлове с доказателства, записани в проекта, така че работят и на втори компютър, и за целия екип.

Нищо не работи зад гърба ви: работата става във вашите Codex чатове, с вашите права, а назначенията изискват вашето одобрение.

## Как работи

```text
Вие -> Chief of Staff -> Project Director -> Manager на екип -> Специалисти
        (по избор)       (2+ екипа)           (за всеки екип)    (Developer, Designer, ...)
```

## Каталог

| Екип | Роли |
|---|---|
| Development | Manager, Developer, Code Reviewer, Designer, Verifier |
| Marketing | Manager, Strategist, Content Writer, Content Reviewer |
| Sales (само чернови) | Manager, Lead Researcher, Outreach Writer, Pipeline Analyst |
| Всеки проект | Project Director (два или повече екипа); роли по поръчка от празния шаблон |
| Лично | Chief of Staff: вашият асистент и входна точка към всички проекти |

## Бърз старт

Изисквания: Codex Desktop (тествано на Windows), Python 3.10+, Git.

1. Клонирайте repo-то.
2. `python -B scripts/build_plugin.py`, после в Codex: **Plugins > Personal > Codex Bot Mode > Install**.
3. Добавете своя проект в Codex, започнете чат и кажете: *„Start a Development team in this project.“*
4. Изберете стойности по подразбиране или отговорете на въпросите, прегледайте плана и потвърдете. Вашият чат става Manager.
5. Дайте задача на Manager-а.

Подробно (на английски): [Getting started](docs/getting-started.md), [Working with teams](docs/working-with-teams.md).
