# Owner knowledge

Private facts about the owner, kept current by the Chief of Staff. Empty in the
template. Record only facts confirmed by the owner, noting the date, source, and
confidence (confirmed vs. unknown). Never store credentials, tokens, or one-time codes.
Retrieve personal context selectively only when directly relevant to the owner's
request; never share personal knowledge automatically with project agents. Correct
or remove entries as soon as obsolete information is identified.

| File | Contents |
|---|---|
| `owner.md` | Identity basics, roles, goals, working hours, communication style |
| `personal.md` | Background, goals, family, friends, habits, key dates and personal boundaries |
| `preferences.md` | How the owner wants things done, approval expectations, dislikes |
| `people.md` | Important people and how the owner relates to them |
| `projects.md` | Projects, their purpose and their Director or Manager deep link |
| `accounts.md` | Services and accounts in use (names only, never secrets) |
| `routines.md` | Recurring commitments, reminders and reviews |
